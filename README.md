# tg-stories

Публикует сториз в Telegram-канал @producer_chmonya от имени личного аккаунта.
Запускается из Google-таблицы «Автопостинг» (Stories.gs) или вручную: Actions → «Сториз в Telegram-канал» → Run workflow.

Секреты (Settings → Secrets and variables → Actions): `TG_API_ID`, `TG_API_HASH`, `TG_SESSION` (получить через `login.py` в Google Colab).
